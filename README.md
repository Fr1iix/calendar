На текущий момент на backend части мы сделали рабочую авторизацию и регистрацию. В регистрации имеется подтверждение почты по коду. Также база данных была доведена до ума (убрали лишние элементы БД и добавлены новые). На frontend части полностью подготовлена админ-панель: статистика, добавление мероприятий, заявки соревнований, список пользователей, добавление новостей. В админ-панель обычный пользователь не может зайти, это было предусмотрено.
